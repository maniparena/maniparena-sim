# EX001 使用指南

# 遥操作采集

采集入口为 `scripts/collect.py`，配置文件按控制方式区分（`keyboard` / `vuer`）。

## 支持的任务

| Task | 说明 |
|------|------|
| `sort_blocks` | 将彩色方块放到对应彩纸上 |
| `fruits_to_basket` | 将水果放入粉色篮子 |
| `buttons_contact` | 依次触碰三个彩色按钮 |
| `put_bottle_on_woodshelf` | 桌面取瓶放到木架（静态场景；资产在 `assets/put_bottle_on_woodshelf/`） |

桌面任务场景使用 `assets/green_booth/green_booth_mesh_ground.usd` 展台（材质在
`assets/green_booth/materials/`，2D lidar 在 `assets/ex001/sensors/`，均已本地化，无远程引用）。
`put_bottle_on_woodshelf` 使用独立 booth/桌/架/瓶资产（`assets/put_bottle_on_woodshelf/`）。

底盘差速使用仿真有效几何：`wheel_radius=0.084`、`wheel_track_width=0.458`
（见 `embodiment/robots/ex001.py`）。Wall-X 全身推理（21D，含 head/lift/底盘）入口：

```bash
python scripts/eval.py \
  --robot ex001 --task put_bottle_on_woodshelf \
  --config configs/eval/ex001_put_bottle.yaml \
  --viz kit
```

## 采集命令

### 键盘

Isaac Lab / Sim **6.0** 默认无界面；需要 Kit 视口时加 `--viz kit`（键盘遥操作必须）。

```bash
python scripts/collect.py \
  --robot ex001 \
  --task fruits_to_basket \
  --control-mode keyboard \
  --config configs/collect/keyboard.yaml \
  --viz kit
```

将 `fruits_to_basket` 换成 `sort_blocks` 或 `buttons_contact` 即可切换任务。

### Vuer（Pico WebXR）

```bash
python scripts/collect.py \
  --robot ex001 \
  --task fruits_to_basket \
  --control-mode vuer \
  --config configs/collect/vuer.yaml \
  --viz kit
```

启动后终端会提示 Vuer 服务地址，默认端口 `8012`（可在 `configs/collect/vuer.yaml` 的 `teleop_config.vuer_port` 修改）。在 Pico 浏览器打开：

```text
https://<运行仿真的机器 IP>:8012
```

接受自签名证书后即可进入 WebXR 遥操作页面。

## 键盘控制

启动后**点击 Isaac Sim 视口**使窗口获得焦点，否则按键无效。

| 按键 | 功能 |
|------|------|
| `B` | 切换控制目标：左臂 → 右臂 → 底盘 |
| `W` / `S` / `A` / `D` / `Q` / `E` | 平移当前目标（手臂或底盘） |
| `Z` / `X` / `T` / `G` / `C` / `V` | 旋转当前手臂（底盘模式下无效） |
| `K` | 切换当前手臂夹爪开/合（映射到关节 `0` ~ `1.89`） |
| `H` | 标记本 episode 成功并导出 |
| `R` | 放弃本 episode / 重置 |

底盘模式下：`W`/`S` 前进后退，`A`/`D` 或 `Q`/`E` 转向。

灵敏度可在 `configs/collect/keyboard.yaml` 调整：

```yaml
teleop_config:
  position_scale: 0.02
  rotation_scale: 0.2
```

## Vuer 控制

首次进入需用**左手 X** 开始遥操作（捕获参考位姿），之后：

| 输入 | 功能 |
|------|------|
| 双手手柄位姿 | 双臂绝对 IK 目标（增量映射到基座坐标系） |
| 扳机（Trigger） | 夹爪连续开合（`0` ~ `1.89`） |
| 左摇杆 | 底盘线速度 / 角速度 |
| 右摇杆 | 升降台（lift） |
| 左手 X | 开始 / 重新捕获遥操作参考 |
| 左手 Y | 标记本 episode 成功并导出 |
| 右手 A | 放弃本 episode / 重置 |

## 录制输出

- 默认目录：`~/maniparena_output/recordings/ex001_<task>_collect/`
- 格式：HDF5 episode + sidecar MP4（左腕 / 右腕 / 头 / 底盘相机）
- 帧率：由配置 `step_hz` 决定，当前统一为 **20 Hz**

示例：

```text
~/maniparena_output/recordings/ex001_fruits_to_basket_collect/
  ex001_fruits_to_basket_collect_vuer_episode0.hdf5
  ex001_fruits_to_basket_collect_vuer_episode0_videos/
    ...
```

# ROS2 导航

## ROS 环境配置

ROS2 桥依赖 Isaac Sim 的 `isaacsim.ros2.bridge` 扩展，需先按官方指南装好 ROS2 环境：

参考：<https://docs.isaacsim.omniverse.nvidia.com/5.1.0/installation/install_ros.html>

## 启动命令

装好 ROS 环境并 `source` 后：

```bash
python scripts/navigate_ros2.py \
  --config configs/navigate/ex001_nav.yaml \
  --enable_cameras \
  --viz kit
```

启动后键盘控制（先点击 Isaac Sim 视口获取焦点）：

| 按键 | 功能 |
|------|------|
| `W` / `S` | 底盘前进 / 后退 |
| `A` / `D` 或 `Q` / `E` | 底盘转向 |
| `R` | 重置机器人到初始位姿 |

外部 ROS2 节点同时可通过 `/chassis/cmd_vel` 驱动底盘，速度与键盘叠加。
